# Zomato_DataAnalysis_1
📊 Project Overview
The project focuses on analyzing Zomato data to extract meaningful insights related to restaurants, ratings, pricing, locations, and customer trends. It demonstrates a complete analytics workflow—from raw data exploration to final business-ready insights.

🛠 Tools & Technologies
1. SQL – Data extraction, cleaning, and transformation
2. Power BI – Interactive dashboards and visual analytics
3. Tableau – Advanced data visualization and storytelling
4. Microsoft Excel – Exploratory analysis and pivot-based insights
5. PowerPoint (PPT) – Final presentation summarizing key findings

Repository Structure
1. Excel/ – Excel analysis files
2. PPT/ – Final presentation with insights and conclusions
3. PowerBI/ – Power BI dashboards and reports
4. SQL/ – SQL queries and analysis scripts
5. Tableau/ – Tableau visualizations and workbooks
